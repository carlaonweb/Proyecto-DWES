## Cómo se abre

- `index.html` abre el menú. El programa funciona en la consola del navegador (F12).

Se abren con doble clic o con Live Server. No hay que instalar nada.

## Regla personal

> `actividadesPopulares()` devuelve las 3 actividades con más inscritos como pares [nombre, inscritos], de mayor a menor. Si dos empatan, va primero la que está antes en orden alfabético.
>
> **Ejemplo:** Pádel 12, Yoga 12, Natación 9, Ajedrez 4 → [["Pádel", 12], ["Yoga", 12], ["Natación", 9]].
>
> **Válido si:** Funciona dentro de tu proyecto, en js/regla.js, y tiene al menos 2 pruebas en js/pruebas.js: una del caso normal y otra del límite o del error.

## Uso de IA

- Herramienta: ChatGPT.
- Para qué la usé: Generar datos de ejemplo para las listas del proyecto.
- Qué le pedí (resumen): Propuestas de actividades deportivas, socios e inscripciones para un club deportivo, respetando la estructura y los requisitos del enunciado.
- Qué cambié yo y por qué: Seleccioné las actividades que más me gustaban, aporté datos propios para los socios y decidí el orden de las inscripciones. También revisé los datos para asegurarme de que cumplían los requisitos.
- Qué he aprendido: He aprendido cómo organizar los datos mediante arrays, utilizar constantes para identificar cada posición y relacionar las distintas listas mediante identificadores.
